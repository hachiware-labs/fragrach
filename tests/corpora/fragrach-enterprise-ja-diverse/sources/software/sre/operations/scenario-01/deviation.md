# 信頼性と本番運用の重要案件レビュー 一時逸脱承認

> 架空の評価用社内文書です。固有名詞・制度・数値は実在組織と無関係です。

## 適用対象

本手順群は、蒼空クラウドにおける信頼性と本番運用の重要案件レビューに関する標準的な運用プロセスを定義するものである。通常、このレビューは案件受付後一営業日以内に実施されるが、特定の例外状況や特別な期間においては、東日本運用センターのSRE-PR-1に限り、より短い時間枠でのレビュー実施が求められる。本文書群は、全社共通の手順と、それを補完・適用する作業指示書、および一時的な逸脱を承認するための手順を含むものであり、各ステップにおける具体的な作業記録や証跡の管理を通じて、運用上のガバナンスを確保することを目的としている。

本逸脱は東日本運用センターのSRE-PR-1だけに適用する。

## 例外規則

この節では、期限内の運用を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

2026年7月1日から2026年7月31日まで、SRE-PR-1では信頼性と本番運用の重要案件レビューを受付後二時間以内に実施する。

## 非対象

この節では、例外の拡張禁止を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。
