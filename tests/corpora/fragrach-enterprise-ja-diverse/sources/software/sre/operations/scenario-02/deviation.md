# 信頼性と本番運用の管理記録確認 一時逸脱承認

> 架空の評価用社内文書です。固有名詞・制度・数値は実在組織と無関係です。

## 適用対象

当部門では、システム全体の信頼性確保と安定的な本番運用を目的として、「信頼性と本番運用の管理記録確認」を実施しています。通常は全社手順に基づき週に一度この作業を行いますが、特定の期間においては例外的に実施頻度を変更し、より厳格な監視体制を敷く必要があります。つきましては、本文書群を通じて、標準的な運用プロセスから一時的な逸脱を含む具体的な作業指示や記録の取り扱いについて確認を行い、部門全体での手順遵守と適切な証跡管理を行うことを目的としています。

本逸脱は東日本運用センターのSRE-EX-2だけに適用する。

## 例外規則

この節では、期限内の運用を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

2026年7月1日から2026年7月31日まで、SRE-EX-2では信頼性と本番運用の管理記録確認を毎営業日の終了時に実施する。

## 非対象

この節では、例外の拡張禁止を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

SRE-EX-2以外には全社手順の「週に一回実施する」を適用する。
