# 脆弱性とアクセス統制の管理記録確認 全社手順

## 対象

当部門では、全社的なセキュリティ基準に基づき、「脆弱性とアクセス統制の管理記録確認」を定期的に実施しています。本手順書は、この標準運用プロセス全体を定めるものであり、特に横浜セキュリティセンターにおける作業指示や一時的な逸脱対応に関する具体的な手続きを定めています。通常は週次での実施が求められますが、特定の例外状況下でより詳細な証跡記録が必要となるケースに対応するため、各関係者は本手順書の内容を熟知し、適切な運用を行う必要があります。

本手順は脆弱性とアクセス統制の管理記録確認の標準運用を定める。

## 頻度

この節では、実施記録について書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

脆弱性とアクセス統制の管理記録確認は週に一回実施する。
