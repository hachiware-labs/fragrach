# 脆弱性とアクセス統制の記録基盤更改 投資審議会議事録

## 議題

現在、脆弱性とアクセス統制の記録基盤について初期検討を進めており、現行の「共有フォルダーを継続利用する」方式と、「横浜セキュリティセンター専用の監査付き記録領域へ移行する」方式の比較評価を行いました。本資料群は、当該記録基盤更改における最適な実施方式を選定し、投資審議を経て正式に決定した経緯をまとめたものです。特に、変更履歴と閲覧権限を一体で追跡できる点で優位性が確認された「横浜セキュリティセンター専用の監査付き記録領域へ移行する」方式を採用することが確定しました。今後の進捗は、段階的な完了記録を通じて確認をお願いいたします。

脆弱性とアクセス統制の記録基盤更改の実施方式を審議した。

## 決定

この節では、採択の結果を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

脆弱性とアクセス統制の記録基盤更改では「横浜セキュリティセンター専用の監査付き記録領域へ移行する」を正式採用した。
