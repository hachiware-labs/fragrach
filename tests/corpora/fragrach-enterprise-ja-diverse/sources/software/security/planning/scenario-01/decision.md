# 脆弱性とアクセス統制業務の標準化 投資審議会議事録

## 議題

当部門では、脆弱性とアクセス統制業務の標準化に向けた実施方式を検討しています。初期提案として「全対象を同日に切り替える」案と、「横浜セキュリティセンターの代表案件から段階的に導入する」案が比較されました。その結果、後者の方式は業務影響度や処理品質を段階ごとに評価できる点で優位性が認められ、正式な実施方式として採用されました。本資料群は、この標準化に向けた検討プロセス、特に方式選定に至る経緯と決定事項を確認するためのものです。

脆弱性とアクセス統制業務の標準化の実施方式を審議した。

## 決定

この節では、採択の結果を書く。 記載された確定事項と文書の適用範囲を合わせて確認する。

脆弱性とアクセス統制業務の標準化では「横浜セキュリティセンターの代表案件から段階的に導入する」を正式採用した。
