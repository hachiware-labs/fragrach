## 目的

当部門では、システム全体のセキュリティレベル維持のため、脆弱性に関する情報およびアクセス統制ログの保存期間について明確な基準を定める必要があります。特に、過去の運用実績や監査対応に備え、記録のライフサイクル管理は極めて重要です。本文書群は、当該記録の保存期間に関する規程（第2版）の最新要件を定め、現場からの疑問点や承認経緯を包括的に整理し、関係部署への周知徹底を図ることを目的としています。

本規程は脆弱性とアクセス統制記録の保存期間を定める。
