# Fragrach 多業種・多目的 日本語企業文書コーパス

Fragrachの改善が特定企業・特定文書型への過適合でないかを確認するための、完全に架空の評価用コーパスです。

- 8業種: 製造、医療・製薬、金融・保険、小売・EC、ソフトウェア・クラウド、建設・エンジニアリング、物流・国際貿易、エネルギー・公共インフラ
- 40部門RAG: 各業種5部門を独立した検索領域として評価
- 6目的: ガバナンス、技術仕様、企画検討、業務手順、障害・変更、契約・コンプライアンス
- 1部門あたり72文書・36質問、合計2,880文書・1,440質問
- 版更新、追補、草案、決裁、期限付き例外、実施記録、契約優先順位、未署名提案を収録

本文の補足段落はOllamaで生成しますが、評価対象の事実は生成器内のWorldで固定され、原文へそのまま挿入されます。したがって、文章表現を多様化しながらGoldの再現性を維持できます。

生成: `npm run corpus:diverse:generate`

検証: `npm run corpus:diverse:check`

部門別Raw RAG評価: `npm run benchmark:diverse:raw`

評価設計は [部門別RAGコーパスの設計と評価方法](../../../docs/enterprise-department-rag-evaluation_ja.md) を参照してください。

生成は文書単位で再開可能で、Ollama応答もプロンプトとモデルのハッシュでキャッシュします。事実設計やプロンプトが変わると別キーになるため、古いキャッシュを誤用しません。

ライセンスは未確定です。自作コーパスとしてパッケージ本体と同一ライセンスにする想定です。
