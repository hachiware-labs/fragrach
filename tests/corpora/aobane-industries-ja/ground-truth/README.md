# 期待値の扱い

`expected.json`は、2026年6月30日時点の文書状態を基準にした主要な期待値です。すべての抽出候補を列挙するのではなく、FRAGARACHの回帰試験で落としてはならない代表例を記録しています。

`expected_claims`の各項目は、少なくとも一つの指定Evidenceへ接続されることを期待します。表現の違いを許容するため、生成IDや完全一致する文章ではなく、正規化した主語、述語、目的語と根拠位置を使っています。

`expected_conflicts`には、現行判断に影響する競合だけでなく、旧版との時間差も含まれます。`resolution`は自動的に真実を確定する指示ではなく、文書の権威性と適用日から期待される診断です。

`event_sequences`は、提案、承認、実装や、規程の複数世代にわたる変更を時系列で固定します。各Eventは状態、値、日付、Evidenceを持ち、単に更新日が新しい文書を選ぶのではなく、質問の対象日時点で有効だった状態を解決する試験に使います。

`not_conflicts`は重要です。議事録に書かれた提案を現行規則として採用したり、下位文書による具体例を上位文書との競合と誤判定したりしないことを確認します。
