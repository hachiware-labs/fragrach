# 公開API版移行の検討メモ

## 背景

公開API v1の利用状況を確認し、v2への移行方法を検討した。本文は技術検討中のメモであり、廃止日や顧客への告知日を決定する正式文書ではない。

## 検討した案

案Aは、v1を六か月間維持してから終了する。案Bは、主要顧客の移行完了を確認するまで最長十二か月維持する。案Cは、v1を読み取り専用として残す。会議では案Bを軸に調査を続けることになったが、採用は決定していない。

## データ形式

v2では時刻表現とページング形式を変更する可能性がある。公開APIまたは保存データ形式の変更に該当する場合、実装開始前に設計レビューが必要である。

## 承認

このメモへの参加者コメントは設計承認ではない。変更内容と移行計画を正式な設計資料へまとめ、リスク区分に応じた承認者へ提出する。

## 顧客連絡

廃止予告は十分な移行期間を確保して行う。連絡文面、対象顧客、問い合わせ窓口はカスタマーサポート部と確認する。具体的な日付は未決定である。

## 次の作業

製品開発部は利用状況を集計し、品質保証部へレビュー区分を相談する。このメモにある期間を現行サービスの規則として案内しない。
