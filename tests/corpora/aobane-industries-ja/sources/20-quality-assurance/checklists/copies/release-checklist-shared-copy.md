# AobaWatch リリース準備チェックリスト

管理部署: 品質保証部  
更新日: 2026年5月20日  
対象: 通常リリース

リリース責任者は、出荷判定会議までに各項目の結果と証跡へのリンクを記録する。

## 設計と試験

- [ ] 対象となる設計レビューが承認済みである。担当: 製品責任者
- [ ] 未解決の高重大度レビュー指摘がない。担当: 主任技師
- [ ] 受入試験が完了し、失敗ケースの扱いが決まっている。担当: 品質保証担当
- [ ] セキュリティ影響がある場合、情報管理責任者の承認がある。担当: 製品責任者

## リリースと復旧

- [ ] リリース手順をステージング環境で確認した。担当: リリース担当
- [ ] ロールバック手順が最新であり、復旧目標時間内に実行できることを確認した。
- [ ] 監視項目とアラート送信先を確認した。担当: 運用担当
- [ ] 顧客向け案内が必要な場合、送信予定と承認者を確認した。担当: カスタマーサポート担当

担当が記載されていない項目を発見した場合、リリース責任者は出荷判定会議で担当者を決める。
