# 認証設定変更時の確認事項

認証または認可に関する設定値を変更する場合は、設定ファイルだけの変更であっても、利用者の操作、権限反映時間、監査ログへ影響する可能性を確認する。

影響がある場合は設計レビューを行い、情報管理責任者を承認者へ加える。影響がないと判断した場合も、確認した項目と根拠を開発チケットへ記録する。
