# 関西工場 生産設備の予防保全運用標準 改訂版

## 目的

既存手順を再整理した版である。 本文は関西工場における生産設備の予防保全の運用境界と記録方法を定める。

## 適用対象

関西工場で実施する予防保全を対象とし、他拠点へは自動的に適用しない。

## 責任分担

関西工場の生産設備の予防保全では、運用管理者が例外記録と対象範囲を照合する。改訂標準に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
