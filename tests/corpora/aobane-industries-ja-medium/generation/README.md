# Ollama生成

企業世界、規則、時点、質問の正解は生成スクリプト内の構造化データを正本とし、Ollamaは各文書の短い導入文を作る。期限、役割、原因、決定などの評価事実は構造化データから本文へ埋め込むため、モデルが正解関係を自由に作り替えることはない。

リポジトリのルートで次を実行する。

```powershell
npm run corpus:m:generate -- --model gemma4:latest
npm run corpus:m:check
```

生成コマンドは既存の妥当な文書を保持して再開できる。全件を作り直す場合だけ`--force`を付ける。生成レポートにはモデル、seed、温度、処理時間、コーパスハッシュ、フォールバックの有無を記録する。

Mコーパスの500文書は、現在Fragrachが解析できるMarkdownとTextに限定する。要求定義にあるPDF、Office文書、CSVなどは、各パーサーが実装された段階で同じWorld Modelから派生させる。
