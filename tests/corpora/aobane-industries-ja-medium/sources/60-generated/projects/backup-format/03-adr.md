# 長期バックアップ形式 ADR

## 状況

長期バックアップ形式に関する技術判断として、将来の復元手段を確保できる公開仕様のアーカイブ形式を採用し、製品固有形式は採用しないと記録する。

長期バックアップ形式の技術判断を記録する。

## 決定

採用案は公開仕様のアーカイブ形式である。

## 理由

判断理由は将来の復元手段を確保するため。

## 不採用案

製品固有形式は採用しない。
