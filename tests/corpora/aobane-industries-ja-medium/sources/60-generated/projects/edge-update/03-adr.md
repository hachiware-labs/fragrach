# ゲートウェイ更新 ADR

## 状況

ゲートウェイ更新における技術判断として、現地設備への一斉影響を避けるため段階配信と自動停止を採用する。

ゲートウェイ更新の技術判断を記録する。

## 決定

採用案は段階配信と自動停止である。

## 理由

判断理由は現地設備への一斉影響を避けるため。

## 不採用案

全台同時配信は採用しない。
