# 公開APIの版管理 意思決定会議

## 議題

公開APIの版管理方式に関する意思決定会議の議事録であり、メジャー版をURLへ含める方式を採用することで、移行期間を明示できるとした。

公開APIの版管理の方式を議題とした。

## 比較

日付だけの版番号とメジャー版をURLへ含める方式を比較した。

## 決定

公開APIの版管理ではメジャー版をURLへ含める方式を採用すると決定した。

## 後続作業

採用理由は移行期間を明示できるため。
