# 社内検索基盤 ADR

## 状況

社内検索基盤の技術判断として、機密区分ごとの移行検証が必要なため、既存基盤の段階的更新を採用する。

社内検索基盤の技術判断を記録する。

## 決定

採用案は既存基盤の段階的更新である。

## 理由

判断理由は機密区分ごとの移行検証が必要なため。

## 不採用案

外部SaaSへの全面移行は採用しない。
