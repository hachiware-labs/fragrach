# 互換性のないスキーマ変更標準 第2版

## 目的

本標準は互換性のないスキーマ変更に関する現行運用を定め、2026年4月1日以降は製品責任者と主任技師の承認が必要である。

この標準は互換性のないスキーマ変更の現行運用を定める。

## 現行規則

2026年4月1日以降、互換性のないスキーマ変更は製品責任者と主任技師が承認する。

## 責任

責任者は主任技師である。

## 旧版の扱い

旧版の「製品責任者だけが承認する」は現行判断に用いない。
