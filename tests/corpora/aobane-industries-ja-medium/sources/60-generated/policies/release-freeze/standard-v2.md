# 年末の本番変更凍結標準 第2版

## 目的

本標準は年末の本番変更凍結の現行運用を定め、2026年4月1日以降は十二月二十二日から開始することを規定しています。

この標準は年末の本番変更凍結の現行運用を定める。

## 現行規則

2026年4月1日以降、年末の本番変更凍結は十二月二十二日から開始する。

## 責任

責任者は製品責任者である。

## 旧版の扱い

旧版の「十二月二十五日から開始する」は現行判断に用いない。
