# 関西第3工場 特権アカウントの棚卸し過去特例控え

## 目的

過去の繁忙期に使用した条件の控えである。 本文は関西第3工場における特権アカウントの棚卸しの運用境界と記録方法を定める。

## 適用対象

関西第3工場で実施する権限棚卸しを対象とし、他拠点へは自動的に適用しない。

## 責任分担

関西第3工場の特権アカウントの棚卸しでは、現場責任者が引継ぎ記録と対象範囲を照合する。過去特例に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
