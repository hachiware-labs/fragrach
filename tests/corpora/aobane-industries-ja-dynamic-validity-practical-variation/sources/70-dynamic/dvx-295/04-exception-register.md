# 北海道第6工場 特例管理台帳

## 適用対象

北海道第6工場で実施する権限棚卸しを対象とし、他拠点へは自動的に適用しない。

## 責任分担

北海道第6工場の特権アカウントの棚卸しでは、現場責任者が引継ぎ記録と対象範囲を照合する。特例台帳に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
