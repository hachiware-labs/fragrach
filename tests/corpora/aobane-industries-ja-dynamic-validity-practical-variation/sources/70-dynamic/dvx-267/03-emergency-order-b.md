# 関西第6工場 一時Exportファイルの後処理緊急指示B

## 目的

## 適用対象

関西第6工場で実施するExport後処理を対象とし、他拠点へは自動的に適用しない。

関西第6工場の一時Exportファイルの後処理では、文書管理担当が監査証跡と対象範囲を照合する。緊急指示に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
