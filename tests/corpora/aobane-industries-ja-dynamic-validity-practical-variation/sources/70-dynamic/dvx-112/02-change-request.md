# 中部第3工場 一時Exportファイルの後処理変更申請

## 目的

運用条件の変更を審査へ付す申請文書である。 本文は中部第3工場における一時Exportファイルの後処理の運用境界と記録方法を定める。

## 適用対象

中部第3工場で実施するExport後処理を対象とし、他拠点へは自動的に適用しない。

## 責任分担

中部第3工場の一時Exportファイルの後処理では、文書管理担当が監査証跡と対象範囲を照合する。変更申請に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。

## 事前確認

中部第3工場の一時Exportファイルの後処理では、運用管理者が実施記録と対象範囲を照合する。変更申請に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
