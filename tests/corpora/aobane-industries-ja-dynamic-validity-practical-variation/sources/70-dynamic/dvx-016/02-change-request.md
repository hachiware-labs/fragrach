# 関西工場 受入部材の抜取検査変更申請

## 目的

運用条件の変更を審査へ付す申請文書である。 本文は関西工場における受入部材の抜取検査の運用境界と記録方法を定める。

## 適用対象

関西工場で実施する受入検査を対象とし、他拠点へは自動的に適用しない。

## 責任分担

関西工場の受入部材の抜取検査では、品質保証担当が確認票と対象範囲を照合する。変更申請に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。

## 事前確認

関西工場の受入部材の抜取検査では、文書管理担当が例外記録と対象範囲を照合する。変更申請に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
