# 中部第6工場 受入部材の抜取検査過去特例控え

## 目的

過去の繁忙期に使用した条件の控えである。 本文は中部第6工場における受入部材の抜取検査の運用境界と記録方法を定める。

## 適用対象

中部第6工場で実施する受入検査を対象とし、他拠点へは自動的に適用しない。

## 責任分担

中部第6工場の受入部材の抜取検査では、品質保証担当が確認票と対象範囲を照合する。過去特例に記載された数値だけを転記せず、作業対象、実施日、承認経路、関連する記録番号を確認する。差異がある場合は判断を保留し、文書管理担当へ照会した経緯を残す。
